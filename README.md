# 🌾 StubbleLink

### Agricultural Residue Recovery & Pickup Coordination Platform

StubbleLink is a platform designed to help **farmers, processors, and transporters coordinate agricultural residue recovery**.

The goal is to make agricultural residue such as crop stubble easier to **collect, transport, and put to productive use** instead of being unnecessarily burned or wasted.

> 🚧 **Current Status: Phase 0 — Project Initialization**

---

## 🎯 What is StubbleLink?

StubbleLink aims to connect the key participants in the agricultural residue recovery process:

- 👨‍🌾 **Farmers** — List available agricultural residue.
- 🏭 **Processors** — Find residue that meets their requirements.
- 🚛 **Transporters** — Coordinate collection and transportation.
- ♻️ **Recovery** — Help redirect agricultural residue toward useful applications.

The project is being developed incrementally, with each phase introducing new functionality.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

- **Node.js**
- **npm**
- **Git**

### Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
cd stubblelink
```

Install dependencies:

```bash
npm install
```

Set up the database:

```bash
npx prisma generate
npx prisma db push
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
